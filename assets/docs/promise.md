# 记忆为何如此深刻

山茶花读不懂白玫瑰，北山的风吹不到南山尾

人们要是没有回忆就活不下去，但是只有回忆的话也活不下去，有些人也说不上哪里好就是忘不掉

梦总是有会醒来的时候，不会醒的梦总有一天会变成悲伤



## 在一起的意义是什么呢 

大概是彼此照亮 成为彼此的避风港和精神寄托 让本就平淡的生活感到一丝美好 

在每个情绪低落的夜里有个依托 在平庸无望的时候发现更好的自己 

有些话无法对父母说出口 对朋友说又差点意思 

但和对方说 就像是给无处安放的灵魂 找到了一个可以依靠的港湾



## 当梦想和现实的天平不再对等，该如何选择？

我贪心我希望你身边一直是我。

我也只想好好被爱一回 

我真的是特别没有安全感的人 

容易患得患失 

爱的是一种感觉
权衡利弊以后的门当户对
我好似从来都不能决定自己的生活
往往别人的三言两语便将我的爱情工作和生活冲击的支离破碎
这一刻我真的渴望在这座生了几年的城市里有一间自己的房子
有一个等待我每天回家的女人
从此告别局无定所
告别夜晚的孤独
告别活着的心酸

种树人希望的是，栽一棵为自己乘凉的树

有钱只能不辛苦，有爱才能好好活！

钱比爱重要，但爱比钱幸福！
